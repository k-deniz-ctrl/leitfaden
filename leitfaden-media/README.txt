LEITFADEN MEDIA – Website
=========================

Die Website ist bewusst als eine einzige Datei gebaut: index.html
Damit lässt sie sich sehr einfach bei GitHub Pages, Netlify, Cloudflare Pages oder normalem Webspace veröffentlichen.

Vor Veröffentlichung anpassen:
1. Namen und Rollen im Bereich "Unser Team"
2. E-Mail-Adresse hallo@leitfaden-media.de, falls abweichend
3. Instagram-Link
4. Impressum und Datenschutz mit echten Rechtstexten verlinken
5. Projekt-/Teamfotos einsetzen

Domain: www.leitfaden-media.de

Tipp: Öffne index.html per Doppelklick im Browser, um die Seite lokal anzusehen.
